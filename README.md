# kemalmaulana.github.io

Personal portfolio and CV of **Kemal Maulana**, Project Manager & Mobile Engineer (Bandung, Indonesia).

Live: https://kemalmaulana.github.io/

## Stack

- [Astro](https://astro.build) (static output)
- [Tailwind CSS](https://tailwindcss.com) v4
- Playwright (CV PDF generation)
- GitHub Actions → GitHub Pages

## Project structure

```
src/
  data/          profile, experience, skills, education (JSON), projects (generated)
  layouts/       Base.astro: meta, Open Graph, JSON-LD, rel="me"
  pages/         index (home), cv (print route), 404
  components/    ProjectCard.astro
  styles/        global.css (Tailwind theme tokens)
scripts/
  fetch-github.mjs   regenerate projects.json from curated GitHub repos
  build-cv.mjs       render /cv to public/cv.pdf
public/          avatar, favicon, robots.txt, llms.txt, cv.pdf
legacy/          previous single-file site (kept for reference)
```

Content lives in `src/data/*.json`. The home page and the CV PDF read from the same data.

## Development

Requires Node.js 22+.

```bash
npm ci
npm run dev          # local dev server
npm run build        # static build → dist/
npm run build:cv     # regenerate public/cv.pdf (run after build)
npm run fetch:github # refresh projects.json (needs `gh` CLI, authenticated)
```

### Updating content

- Profile, experience, skills, education: edit `src/data/*.json`.
- Projects: edit the `show` list and overrides in `src/data/projects.overrides.json`, then run `npm run fetch:github`. Only public, non-fork repos can be listed.
- After content changes, run `npm run build` and `npm run build:cv`, then commit `public/cv.pdf` too.

## Deployment

Pushes to `main` run `.github/workflows/deploy.yml`, which builds with `npm run build` and deploys `dist/` to GitHub Pages.

Pages source must be set to **GitHub Actions** (Settings → Pages → Build and deployment).

`.nojekyll` at the repo root stops Jekyll from processing the Astro source files.

## SEO / AI discoverability

- schema.org JSON-LD: `WebSite`, `Person`, `ProfilePage`
- `rel="me"` links to GitHub and LinkedIn
- `public/llms.txt`: plain-text summary for AI assistants
- `sitemap-index.xml` generated by `@astrojs/sitemap`
